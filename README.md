# LCDCockpit (LCD)

## Features
LCDCockpit is a skin for Enigma2 receivers with a 790x480 pixel LCD/VFD front panel display, based on the OpenViX "display800" skin. It provides custom summary screens for the info bar, channel selection, EPG, standby, and all standard Enigma2 dialogs - see the [screen gallery](docs/gallery.md) for previews of every screen.

## Limitations
- Supports Enigma2 on OpenViX and compatible distributions only
- Is being tested on DM9xx only
- Requires a 790x480 or 390x240 pixel LCD/VFD display
